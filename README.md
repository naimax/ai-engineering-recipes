# AI Engineering Recipes

Рецепты инженерных практик работы с ИИ-агентами: как собрать **своё** под свойство работы, которое нужно удержать. Правила для агента, среда вокруг него, цикл, который сам решает что повторить, передача результата человеку.

Здесь нет готовых файлов на копипаст. Публичных коллекций уже достаточно, и почти четверть строк в них: буквальные копии чужих файлов. Копия описывает чужую работу, поэтому у себя она либо не срабатывает, либо съедает контекст.

## Что такое рецепт

Папка из трёх частей. Ни одна не заменяет другие.

| Часть | Файл | Что даёт |
|---|---|---|
| Нотация | `notation.md` | из каких мест состоит артефакт практики и как формулировать так, чтобы срабатывание можно было проверить |
| Ближайшие промпты | `prompts.md` | команды агенту, которыми это заводится, проверяется и правится; дополняете именами своих проектов |
| Опорные документы | `sources.md` | что дать агенту как основание: ваши файлы, чтобы он работал из вашей практики, и одна внешняя статья, задающая уровень формулировки |

**Пишет агент, не вы руками.** Это не стилистическое предпочтение: цикл разбирает ровно тот случай, когда человек вручную дописывает файл после каждой ошибки, файл растёт, а поведение не меняется. Рецепт даёт промпт и опоры, дальше работает агент, вы читаете результат и говорите «да» или «нет».

## Как пользоваться

```bash
git clone https://github.com/naimax/ai-engineering-recipes.git
cd ai-engineering-recipes
```

1. Выберите папку в `recipes/` под свою поломку.
2. Прочитайте `notation.md` (пять минут, форма).
3. Соберите опоры по списку `sources.md`: это ваши файлы, не наши.
4. Скопируйте блок из `prompts.md` целиком в чат с агентом и замените то, что в угловых скобках, вместе со скобками. Блоки самодостаточны: агенту не нужно читать этот репозиторий.
5. Прогоните проверку из `notation.md` §Проверяемость: сделанное либо меняет поведение, либо это текст.

Копируются **промпты и скелеты**, то, что вы дополняете своим. Готовых файлов правил на перенос здесь нет: если после рецепта в вашем репозитории появился скопированный отсюда файл правила, рецепт применён неверно.

Структура репозитория:

```
ai-engineering-recipes/
├── common/                     то, что держит любой рецепт
│   └── README.md               четыре условия + чем они проверяются
└── recipes/
    ├── README.md               оглавление папок
    ├── rule-under-a-job/
    ├── agent-under-a-job/
    └── many-agents/
```

Оглавление и классы поломок: [`recipes/README.md`](recipes/README.md).

## Границы и лицензия

- Ноль наших внутренних путей, имён требований и инцидентов с деталями. Примеры синтетические.
- Ни один скрипт отсюда не является вердиктом: скрипт даёт числа, смысл проверяет человек.
- Репозиторий читается целиком за десять минут. Если он перестанет читаться, он сам станет тем, про что цикл.
