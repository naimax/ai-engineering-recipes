# Ближайшие промпты

Charter пишет агент. Скопируйте блок целиком, замените `<…>`.

Порядок: подготовка (0 / 0a) → charter (1) → проверка чат/агент (2) → после сбоя (3).

## Подготовка

### 0a. Уровень дисциплины agent engineering

```text
Прочитай https://agentengineering.org/articles/what-is-agent-engineering/ — секции «Five Jobs» и «What Usually Fails».

Список: какие два из пяти jobs у моей задачи <описание задачи> сейчас не закрыты (контекст, tools, eval, ops…).

Одна строка: что должно появиться в charter, чтобы закрыть главный gap. Ничего в файлы не пиши.
```

### 0. Задать уровень «агент vs workflow»

```text
Прочитай https://www.anthropic.com/engineering/building-effective-agents — разделы «What are agents?» и «Building block: The augmented LLM».

Своими словами: чем workflow (фиксированный код) отличается от agent (модель сама выбирает tools). Приведи один пример из моего проекта <корень репо>: где сейчас workflow, а где нужен agent.

Ничего в файлы не пиши.
```

## Завести charter и прогнать задачу

```text
Я завожу агента под задачу: <одно предложение>.

Корень репозитория: <путь>. Инструмент: Cursor Agent (или Claude Code / Codex — укажи свой).

Перед charter прочитай (не по памяти):
- https://cursor.com/docs/agent/overview
- https://www.anthropic.com/engineering/building-effective-agents (Appendix 2 про tools)

Создай файл `agent-charter.md` в <папка, напр. docs/agents/> по нотации:
роль, задача, таблица tools, ≥3 Never, успех (команда или файл), таблица «чат vs агент».

Не копируй готовые промпты из интернета. Примеры в таблице «против чего» — из моей задачи, не синтетика.

Покажи diff. Не выполняй задачу — только charter.
```

Прогон с проверкой:

```text
По `agent-charter.md` выполни задачу: <конкретная задача>.

Правила:
- Каждое утверждение «сделано» сопровождай выводом tool (команда, путь, фрагмент stdout).
- Если пункт из Never — остановись и спроси.
- В конце: три строки PASS/FAIL по чеклисту из notation §«Чат vs агент».
```

## После ответа «всё готово» без вывода

```text
В этом чате ты сказал, что <действие> выполнено, но не показал вывод tool.

По charter: это чат или агент? Цитируй строку charter, которую нарушен ответ.

Предложи одну правку в charter (не переписывай файл) — что добавить в Never или в «Успех», чтобы такой ответ ловился.
```
