# Нотация: агент под класс работы

Связанная практика: после [статьи о правилах для агента](https://habr.com/ru/articles/1074764/) здесь кто исполнитель и чем может трогать систему.

Форма charter, не промпт на копипаст. Заполняете под свою работу.

## Из чего состоит charter агента

| Место | Что пишете | Признак плохого заполнения |
|---|---|---|
| Роль | одно предложение: кто агент в этой задаче (не «помощник») | «умный помощник разработчика» |
| Задача | что должен закончить (артефакт, не процесс) | «помочь с кодом» |
| Tools | список: что может вызвать + что каждый tool делает | «всё что нужно» без перечня |
| Never | ≥3 пункта: что только человек | один Never «не ломай прод» |
| Успех | как проверить без слов агента (команда, файл, diff) | «если агент сказал OK» |
| Против чего | пара «чат / агент» из реального сбоя | выдуманный пример |

## Скелет charter (копируемый)

```markdown
# Agent: <роль одной строкой>

## Роль
<кто этот агент в задаче, не persona-био>

## Задача
<что должно существовать на диске или в CI после завершения>

## Tools (разрешено)
| Tool | Когда вызывать | Что НЕ делает |
|------|----------------|---------------|
| <read/search> | найти файл, прочитать | не правит |
| <edit/shell> | … | … |

## Never (только человек)
1. …
2. …
3. …

## Успех (проверка без слов агента)
- Команда: `<…>`
- Или файл: `<путь>` содержит `<…>`

## Против чего
| Чат (плохо) | Агент (хорошо) |
|-------------|----------------|
| «Тесты прошли» без вывода | план в абзаце, 0 Edit в trace |
```

## Чат vs агент (быстрый тест)

Перед публикацией charter на задачу:

1. Агент назвал tool и показал сырой вывод. Нет: чат.
2. Действие из Never. Да: чат с нарушением.
3. Успех проверяется командой или файлом, не тоном ответа. Нет: чат.

## Проверяемость

Charter готов, когда на нарушающий и законный входы вы можете сказать PASS/FAIL по таблице «Против чего» без перечитывания всего чата.
