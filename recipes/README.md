# Рецепты

Одна папка: одна практика и один класс поломки. Внутри каждой три файла: нотация, промпты, опоры (см. [корневой README](../README.md) §Что такое рецепт).

| Папка | Класс поломки | Статья цикла | Статус |
|---|---|---|---|
| [`rule-under-a-job/`](rule-under-a-job) | Правила есть, агент их нарушает или они не подгружаются; в репозитории лежит скопированная чужая коллекция | [Harness engineering: контроль правил агента и где ломается](https://habr.com/ru/articles/1074764/) | готово |
| `environment-around-agent/` | Проверки зелёные, а необратимое снесено: у агента нет ролей, гейтов и журнала | Среда вокруг агента (harness) | собранный пример есть в [`agent-harness-reference`](https://github.com/naimax/agent-harness-reference); нотация и промпты планируется |
| [`agent-under-a-job/`](agent-under-a-job) | Модель без роли, инструментов и границ («умный чат», а не агент) | Агент-инжиниринг (#14) | стейджинг: notation, prompts, sources, **variations** 2026-08-28 |
| `context-under-a-job/` | В одно окно свалены правила, история, вывод инструментов и целые файлы; указания не соблюдаются, потому что не помещаются рядом с задачей | Контекст-инжиниринг | планируется |
| `loop-under-a-job/` | Человек каждый раз руками пишет «проверь ещё раз»; цикла нет | Цикл-инжиниринг | планируется |
| `handover-to-a-human/` | Агент выдаёт гладкий результат, который человек не может принять | Когнитивный инжиниринг | планируется |
| [`many-agents/`](many-agents) | Гейт между проходами: самоаппрув, факт в чате, зоны записи | Кто ставит вердикт (#17) | готово 2026-08-31 |
| `orchestration/` | Цепочка без дирижёра; стадии в одном ходу; параллель без разведения | Мультиагенты и оркестрация (#17a) | планируется (seed 2026-08-31); после #17 |
| `skills-and-mixes/` | Либо простыня правил, либо навык без границы; сочетания не описаны | Навыки и сочетания | планируется |
| `companion/` | Ассистент «в чате» без памяти рабочего контура; путает совет и действие | Компаньон | планируется |
| `stack/` | Собрали по одной папке, вместе снова рассыпается | Сочетание практик | планируется |

Папка появляется вместе со статьёй, а не заранее: пустой каталог обещает то, чего нет.
