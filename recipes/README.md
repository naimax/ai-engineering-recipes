# Рецепты

Одна папка: одна практика и один класс поломки. Внутри каждой три файла: нотация, промпты, опоры (см. [корневой README](../README.md) §Что такое рецепт).

| Папка | Класс поломки |
|---|---|
| [`rule-under-a-job/`](rule-under-a-job) | Правила есть, агент их нарушает или они не подгружаются; в репозитории лежит скопированная чужая коллекция |
| [`agent-under-a-job/`](agent-under-a-job) | Модель без роли, инструментов и границ («умный чат», а не агент) |
| [`many-agents/`](many-agents) | Гейт между проходами: самоаппрув, факт в чате, зоны записи |

Собранная среда (роли, гейты, журнал) как рабочий пример, не рецепт: [`agent-harness-reference`](https://github.com/naimax/agent-harness-reference).
